=======================================

BASE URL (Development): http://localhost:5001

--------------------------------------------------------------------------------
1. AUTHENTICATION
--------------------------------------------------------------------------------

[POST] /api/auth/register
Description: Create a new candidate account.
Headers: Content-Type: application/json
Body:
{
  "email": "candidate@example.com",        // Required, valid email
  "password": "SecurePass123!",            // Required, min 8 chars, 1 upper, 1 lower, 1 number
  "fullName": "John Doe"                   // Required, min 2 chars
}
Response (201 Created):
{
  "success": true,
  "message": "User registered successfully",
  "data": {
    "user": {
      "id": "65ae64b1f481234567890abc",
      "email": "candidate@example.com",
      "fullName": "John Doe",
      "role": "CANDIDATE"
    },
    "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}

[POST] /api/auth/login
Description: Authenticate and receive tokens.
Headers: Content-Type: application/json
Body:
{
  "email": "candidate@example.com",

}

  }

[POST] /api/auth/fcm-token
Description: Register device for push notifications.
Headers: Content-Type: application/json, Authorization: Bearer <access_token>
Body:
{
  "fcmToken": "c4b2447b5626db082ef578..." // Required
}
Response (200 OK):
{
  "success": true,
  "message": "FCM Token updated successfully"
}

ERROR HANDLING
--------------------------------------------------------------------------------
Standard Error Format:
{
  "success": false,
  "message": "Error description here",
  "errors": [ { "field": "email", "message": "Invalid email" } ] // Optional validation details
}

Common Errors:
- 404 Route not found: Ensure the URL includes the '/api' prefix and the ID (if any) is a valid 24-char MongoID.
- 400 Validation failed: Check request body fields against requirements.
